<task type="auto">
  <name>Task 1: Create adapter.schema.yaml</name>
  <files>schemas/adapter.schema.yaml</files>
  <action>
Create `schemas/adapter.schema.yaml` with JSON Schema Draft 7 format.

Derive the schema from the actual structure of existing adapters (software-development.yaml, research.yaml). The schema must define:

**Required top-level fields:**
- `name` (string): Unique adapter identifier
- `description` (string): Human-readable description
- `version` (string): Semantic version

**Required sections (each as object):**
1. `questioning`:
   - `init_questions` (array): Each with category, question, why, options_template

2. `decomposition`:
   - `subgoal_heuristics` (array): Each with name, description, examples, when_to_use
   - `atomicity_criteria` (array): Each with criterion, check, fail_signal
   - `max_recursion_depth` (integer, default 5)

3. `constitution`:
   - `template` (string): Multi-line template with placeholders

4. `artifacts`:
   - `types` (array): Each with name, extensions, description
   - `verification_strategies` (object): Keyed by artifact type, array of method objects

5. `dependencies`:
   - `common_patterns` (array): Each with name, from_type, to_type, description, confidence
   - `inference_hints` (array): Each with pattern, implies

Follow existing schema conventions:
- Use `$schema: "http://json-schema.org/draft-07/schema#"`
- Use `$id` with file:// or relative URI
- Include `title` and `description` at schema level
- Use `additionalProperties: false` for strict validation
- Include inline comments explaining each section purpose
  </action>
