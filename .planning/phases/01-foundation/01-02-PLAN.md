```yaml
name: ptf

```

**Required sections:**

1. **Core Concepts** - Define: Task, Wave, Artifact, Dependency, Plan, Context Budget
   - Task: atomic unit of work with inputs, outputs, verification
   - Wave: set of independent tasks that execute in parallel
   - Artifact: file produced/consumed by tasks
   - Dependency: relationship where one task must complete before another
   - Plan: complete execution blueprint with tasks, dependencies, waves
   - Context Budget: token limits to maintain quality (target 10-30% of window)

2. **File Locations** - Table of .orchestrator/ paths
   - .orchestrator/config.yaml
   - .orchestrator/decomposition/
   - .orchestrator/execution/
   - .orchestrator/artifacts/
   - .orchestrator/history/

3. **Context Budget** - Quality degradation curve
   - 0-30%: Peak quality
   - 30-50%: Good quality
   - 50-70%: Degrading
   - 70%+: Poor quality
   - Heuristic: ~4 chars = 1 token

4. **Commands** - Table of /ptf:* commands
   - /ptf:init [goal]
   - /ptf:decompose
   - /ptf:plan
   - /ptf:execute [wave]
   - /ptf:execute-all
   - /ptf:status
   - /ptf:verify [task]
   - /ptf:resume
   - /ptf:retry [task]
   - /ptf:abort

5. **Schema Reference** - Brief overview pointing to schemas/
   - Task schema fields
   - Artifact schema fields
   - How schemas relate

6. **Subagents** - List of PTF agents
   - ptf-decomposer: breaks goals into tasks
   - ptf-dependency-analyzer: infers dependencies, computes waves
   - ptf-task-executor: executes single task with fresh context
   - ptf-verifier: independently verifies task outputs
   - ptf-orchestrator: coordinates wave-by-wave execution

Use research from 01-RESEARCH.md for accurate details.
