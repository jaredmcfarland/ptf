**Task Schema (schemas/task.schema.yaml):**
- $schema: JSON Schema Draft 7
- Required fields: id, name, description, outputs, verify
- Optional fields: inputs, context_notes, context_budget, on_failure
- id: string with pattern ^[a-z0-9-]+$
- name: string, maxLength 100
- description: string (execution instructions)
- inputs: array of TaskInput objects (path, description, required)
- outputs: array of TaskOutput objects (path, type enum: source-code, config, test, migration, documentation, data, schema)
- verify: array of VerificationStep objects (type enum: exists, contains, runs, syntax, custom; target, expected)
- context_budget: object with estimated_input_tokens (integer) and max_context_percentage (number 0-100, default 30)
- on_failure: object with strategy enum (retry, skip, escalate), max_attempts (integer, default 3)

Use definitions section for TaskInput, TaskOutput, VerificationStep, ContextBudget, FailurePolicy.

**Artifact Schema (schemas/artifact.schema.yaml):**
- $schema: JSON Schema Draft 7
- Required fields: path, type, produced_by
- Optional fields: produced_at, consumed_by, checksum, verified
- path: string (relative to project root)
- type: enum (source-code, config, test, migration, documentation, data, schema)
- produced_by: string (task ID)
- produced_at: string, format date-time
- consumed_by: array of strings (task IDs)
- checksum: string (SHA-256)
- verified: boolean, default false

Reference the research patterns from 01-RESEARCH.md for exact field structures.

Implement the remaining three schemas following JSON Schema Draft 7.

**Dependency Schema (schemas/dependency.schema.yaml):**
- $schema: JSON Schema Draft 7
- Required fields: from, to, type
- Optional fields: confidence, reason
- from: string (prerequisite task ID)
- to: string (dependent task ID)
- type: enum (artifact, semantic, resource, implicit)
- confidence: enum (high, medium, low), default medium
- reason: string (human-readable explanation)

**Wave Schema (schemas/wave.schema.yaml):**
- $schema: JSON Schema Draft 7
- Required fields: number, tasks, status
- Optional fields: depends_on_waves, started_at, completed_at
- number: integer, minimum 1
- tasks: array of strings (task IDs), minItems 1
- status: enum (pending, running, completed, partial, failed), default pending
- depends_on_waves: array of integers
- started_at, completed_at: string, format date-time

**Plan Schema (schemas/plan.schema.yaml):**
- $schema: JSON Schema Draft 7
- Required fields: id, goal, tasks, waves
- Optional fields: created, analysis, dependencies, execution_policy
- id: string with pattern ^[a-z0-9-]+$
- goal: string
- created: string, format date-time
- analysis: object with objective, scope (included/excluded arrays), constraints (array), success_criteria (array), domain (string)
- tasks: array, items reference task schema pattern
- dependencies: array, items reference dependency schema pattern
- waves: array, items reference wave schema pattern
- execution_policy: object with max_parallel (integer), failure_strategy (enum), checkpoint_frequency (enum)

Use $ref for cross-schema references where appropriate.
