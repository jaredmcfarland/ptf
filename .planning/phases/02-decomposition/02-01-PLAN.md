<objective>
Create domain adapters that customize PTF decomposition for specific domains.

Purpose: Domain adapters enable the init and decompose commands to ask domain-relevant questions, apply appropriate decomposition heuristics, and generate domain-shaped constitutions. Without adapters, the framework would be domain-agnostic to the point of being generic.

Output: Three YAML adapter files in adapters/ directory (software-development, research, template).
</objective>

   - common_patterns array: schema-to-repository, repository-to-service, service-to-api, code-to-test
