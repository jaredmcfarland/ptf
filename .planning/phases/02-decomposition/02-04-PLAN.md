  <files>.claude/commands/ptf/decompose.md</files>
  <action>
Enhance the decompose command to support resuming from partial decomposition.

Add resume detection in Phase 1:

```markdown
## Phase 1: Validate Prerequisites and Check Resume

1. **Check analysis exists:**
   ```bash
   [ ! -f .orchestrator/decomposition/analysis.yaml ] && \
     echo "Run /ptf:init first" && exit 1
   ```

2. **Check for partial decomposition:**
   ```bash
   # Check if decomposition was started but not completed
   if [ -f .orchestrator/decomposition/subgoals.yaml ]; then
     SUBGOALS_STATUS=$(grep "^status:" .orchestrator/decomposition/subgoals.yaml | cut -d' ' -f2)
     if [ "$SUBGOALS_STATUS" = "in_progress" ]; then
       echo "Partial decomposition found at step 2"
       RESUME_FROM="step2"
     fi
   fi

   if [ -d .orchestrator/decomposition/tasks ] && \
      [ ! -f .orchestrator/decomposition/validation.yaml ]; then
     echo "Partial decomposition found at step 3"
     RESUME_FROM="step3"
   fi

   if [ -f .orchestrator/decomposition/validation.yaml ]; then
     VAL_STATUS=$(grep "^status:" .orchestrator/decomposition/validation.yaml | cut -d' ' -f2)
     if [ "$VAL_STATUS" = "in_progress" ]; then
       echo "Partial decomposition found at step 4"
       RESUME_FROM="step4"
     fi
   fi
   ```

3. **Handle resume:**
   If partial decomposition detected:

   Use AskUserQuestion:
   - header: "Resume Decomposition"
   - question: "Found partial decomposition at {step}. Resume or restart?"
   - options:
     - "Resume" -> Continue from detected step
     - "Restart" -> Clear decomposition state and start fresh

   If "Restart":
   ```bash
   rm -f .orchestrator/decomposition/subgoals.yaml
   rm -rf .orchestrator/decomposition/tasks/
   rm -f .orchestrator/decomposition/validation.yaml
   rm -f .orchestrator/decomposition/graph.yaml
   ```
```

Update subagent prompt to include resume_from if resuming:

```
Task(prompt="
...
Resume from: {RESUME_FROM or "beginning"}
...
")
```
