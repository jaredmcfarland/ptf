Create the resume command based on 04-RESEARCH.md "Resume Protocol" section.

**Required frontmatter:**
```yaml
---
name: ptf:resume
description: Resume PTF execution from last checkpoint after interruption
allowed-tools:
  - Read
  - Write
  - Bash
  - Glob
  - Grep
  - Task
---
```

**Required sections:**

1. **&lt;objective&gt;**
   - Continue execution from last checkpoint after interruption
   - Validate artifacts exist and are unchanged before skipping tasks
   - Handle interrupted tasks (were "running" when session ended)
   - Safe: won't re-execute completed work unless artifacts are invalid
   - Notes: "After resume: /ptf:execute continues from current wave"

2. **&lt;execution_context&gt;**
   - Reference @.claude/skills/ptf/SKILL.md

3. **&lt;context&gt;**
   - @.orchestrator/state/execution.yaml
   - @.orchestrator/artifacts/manifest.yaml
   - @.orchestrator/config.yaml

4. **&lt;process&gt;** with 5 phases:

   **Phase 1: Load State**
   ```bash
   if [ ! -f .orchestrator/state/execution.yaml ]; then
     echo "No execution state found. Run /ptf:execute first"
     exit 1
   fi
   ```
   - Read execution.yaml
   - Check status field

   **Phase 2: Handle Terminal States**
   ```markdown
   If status == "completed":
     Report: "Execution already complete. Nothing to resume."
     Exit: success

   If status == "failed":
     Report blockers from execution.yaml
     Ask user:
       - "retry" -> Clear failed status, retry failed tasks
       - "skip" -> Mark failed tasks as skipped, continue
       - "abort" -> Exit
   ```

   **Phase 3: Validate Completed Artifacts**
   Spawn state manager for validation:
   ```
   Task(prompt="
   Validate all artifacts in .orchestrator/artifacts/manifest.yaml
   For each artifact:
   1. Check file exists
   2. Compute checksum: shasum -a 256 {path}
   3. Compare with stored checksum

   Return VALIDATION RESULTS with:
   - Total artifacts checked
   - Valid count
   - Invalid list (path, reason)
   ", subagent_type="ptf-state-manager")
   ```

   If any invalid:
   - Mark producing tasks for re-execution
   - Update task states: status: ready
   - Append artifact_validation_failed events

   **Phase 4: Handle Interrupted Tasks**
   Tasks with status: running were interrupted mid-execution.
   ```markdown
   For each task where status == "running":
     1. Check if all outputs exist and valid
     2. If outputs valid:
        - Mark task completed
        - Append task_completed event
        - Register artifacts
     3. If outputs invalid/missing:
        - Mark task ready (will retry)
        - Append task_retry event
   ```

   **Phase 5: Prepare Continuation**
   ```markdown
   1. Update session info in execution.yaml:
      - session.id: generate new session ID
      - session.started: now
      - Append session_resumed event

   2. Determine resume point:
      - If current wave has pending/ready tasks: resume wave
      - If current wave complete: advance to next wave

   3. Report resume status:
      Resume Summary:
      - Session: {new-session-id}
      - Resuming from: Wave {N}
      - Tasks re-validated: {count}
      - Tasks to retry: {count}
      - Ready to continue

      Next: Run /ptf:execute to continue
   ```

5. **&lt;validation_logic&gt;**
   Detailed checksum validation:
   ```bash
   # Compute checksum (macOS/Linux compatible)
   compute_checksum() {
     if command -v shasum &> /dev/null; then
       shasum -a 256 "$1" | cut -d' ' -f1
     else
       sha256sum "$1" | cut -d' ' -f1
     fi
   }

   # Compare
   stored="abc123..."
   actual=$(compute_checksum "path/to/file")
   if [ "$stored" != "$actual" ]; then
     echo "Checksum mismatch for path/to/file"
   fi
   ```

6. **&lt;success_criteria&gt;**
   - Execution state validated
   - Artifacts verified with checksums
   - Interrupted tasks handled appropriately
   - Session resumed with new ID
   - Ready for /ptf:execute
